# 六套暗色古典博客原型

本轮仅用于设计方向探索，不替换正式网站，也不包含发布操作。

| 槽位 | 方向 | 主要布局与交互 |
| --- | --- | --- |
| A | 午夜藏书室 | 左侧目录、章节定位、书目筛选、手机折叠菜单 |
| B | 月光石廊 | 中央轴线、横向作品段落、折叠目录、阅读进度 |
| C | 朱砂题签 | 右侧题签、非对称版心、可独立展开的旁注 |
| D | 橄榄标本册 | 编号标本网格、选择摘要、图片放大；手机选择后将摘要滚入视口 |
| E | 午夜剧场 | 宽幅作品开场、折叠幕次、按主题展开的文章节目单 |
| F | 钴蓝画册 | 不等幅拼排、可触摸/按钮/键盘操作的画廊、图文/紧凑索引切换 |

## 本地浏览

总览：/previews/。每套的三个展示页：/previews/design-a/home、/articles、/article；将 a 替换为 b—f 即其他方向。旧 category 路由跳转至该案文章索引；历史 observatory、arcade、atlas 的四个视图仍保留。

六案共用已发布中文文章、项目素材与分类；阅读示例为《动物井》渲染分析。其他文章和项目入口标明前往正式详情。临时宽表格与长标题只在测试浏览器 DOM 中注入，不修改原文。

构建与静态预览：

```powershell
npm run build
python -m http.server 4323 --bind 127.0.0.1 --directory dist
```

默认使用构建产物进行验收，避免开发服务器热更新干扰截图和操作。复用已运行的服务；端口变化时显式传入 --base。

## 检查、独立评审与返工

```powershell
python scripts/preview-audit/capture.py --design design-a --round 1 --base http://127.0.0.1:4323
python scripts/preview-audit/report.py
```

采集脚本覆盖三个视图、1440/1024/390px、真实交互、键盘焦点、对比度、触摸目标、内容增长和宽内容滚动。每轮结果保存在 artifacts/preview-audit/design-<x>/round-<n>/，已归档轮次不能覆盖；最新检查写入 src/data/preview-audit/。截图归档目录由 Git 忽略，保留在本机；总览缩略图及最新报告位于 public/previews-audit/。

独立 agent 按 scripts/preview-audit/review-brief.md 查看实际截图与操作证据，输出每案 score.json 和全部15对的 comparison.json。评分、技术检查、横向比较必须对应当前轮次。report.py 验证完整性及门槛，发布本地可浏览的报告文件；有任何缺项返回非零状态。

总分至少80，且美术>=20/25、阅读>=20/25、差异>=12/15、移动交互>=12/15；所有技术门槛和两两差异要求都必须通过。任意两案至少四轴实际不同，必须含布局及主要交互。技术通过不等于美学合格。

局部问题按独立评审逐项修复并复评；连续两轮同一核心设计问题失败，保留风格短语并重新生成布局/交互。原型只覆盖本轮浏览器和视口测试，不代表所有设备、字体环境或正式上线验收。
