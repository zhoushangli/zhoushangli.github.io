# 六套暗色古典博客 · 实现与返工约定

本轮用户已明确授权独立结构与真实交互，替代旧的“固定 DOM、只能改 CSS”约束；不再沿用随机设计轴锁定或三轮终止规则。

- A 午夜藏书室：左目录、书目筛选与章节定位。
- B 月光石廊：中央轴线、横向作品与折叠目录/阅读进度。
- C 朱砂题签：右侧题签、非对称版心与独立旁注。
- D 橄榄标本册：编号网格、选择摘要与图片检视。
- E 午夜剧场：宽幅作品开场、分幕展开与节目单。
- F 钴蓝画册：不等幅拼排、原生横向画廊与索引视图切换。

每套三个展示视图 home/articles/article，分类并入索引。共享真实内容读取和正文；各案独立布局、样式、局部交互，不修改正式站点和已发布文章。

暗色、可读性、无溢出、可操作与方案差异要求，以及评分最低要求，以 review-brief.md 为准。任意两案至少四个实际维度有差异，必须包含布局与主要交互。

每轮先 npm run build，使用构建产物启动本地静态预览，再执行 capture.py --design design-<x> --round <n> --base <origin>。截图、技术结果、独立评分按轮次保留，不能覆盖既有轮次。report.py 检查当前评分、检查与横向比较是否属于相同轮次，并输出完整汇总。

根据独立评审问题逐项返工并复评。连续两轮同一核心设计问题失败，保留已选风格短语、重新生成布局和主要交互。直到六案通过；遇到真实外部阻碍则报告具体未完成项，不降低标准。

旧原型仍可访问；六案预览 noindex 且不进入 sitemap。不进行推送或正式发布。
